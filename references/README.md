# references：论文、阅读顺序与来源凭据

看论文和代码先打开 **[READING_GUIDE.md](READING_GUIDE.md)**，不必逐个猜 PDF 文件名。

| 位置 | 用途 |
|---|---|
| `papers/research_20261109/` | 12 篇原论文 PDF |
| `sources.json` | 来源、用途、版本、归属、许可的结构化登记 |
| `references.bib` | 毕业论文引用条目 |
| `reading_manifest_20261109.json` | 本批资料的 PDF 哈希/版本、源码 commit/许可 |
| `reading_catalog*.json` | 当时下载选项，不是最新项目进度 |
| `licenses/` | 原始许可快照 |
| `resume.pdf` | 用户个人简历，选题背景资料；不是研究成果，不纳入对外资料包 |

外部代码实际在 upstream；下载原始记录在 runs。论文阅读笔记进 docs/03_learning，研究决策进 docs/01_project，不把 references 变成第二个进度目录。
