# 轮子、键盘和“真的在运行吗”

本轮针对用户看到“轮子不对、Joint 只变小数、鼠标不动、入口功能太多”的反馈，保持 E002 和作者六状态控制链，修正日常交互。当前入口见 [E002 README](../../experiments/E002_original_controller/README.md)，实测与失败见其 REPORT。

## 1. 有窗口不代表物理在推进

旧 `--hold` 在计时结束后只调用 viewer.sync，不再 mj_step，保留的就是静止画面；此前 `--viewer` 也不自动设置键盘 callback，需要另外 `--drive`。这会让用户以为程序在运行、按键/鼠标却无效。当前无参数启动直接是持续键盘驾驶，不再过十秒冻结，关闭窗口结束。左下 RUNNING 时间和真实机身 X 持续更新。有限无窗口评测仍显式 `--headless --duration 10`，timeout 与用户关闭 viewer 分开记录。

调 Joint/Control 面板不等于给高层命令：平衡器每步都写六电机力矩，手填 ctrl 会被下一次控制覆盖。键盘只改速度、转向、腿长/动作目标，控制器继续负责平衡。普通鼠标拖动是相机操作；官方方式是先双击选中物体、再 Ctrl 拖动施力，不能把普通拖相机当机器人受力。

## 2. 外观网格和碰撞不是一回事

原轮子 STL 已经在 assets 内，XML asset 也声明了，但 visual geom 仍是圆柱，所以没有显示源轮的轮毂、胎面细节。当前 load_play_scene 从正式 XML 派生运行场景，将 visual 改回左右源 STL，圆柱仅作隐藏碰撞。原质量、惯量、轮轴、半径和摩擦没有跟着改，也不将 STL 换成凸包或猜测重建。

灰色棋盘只是一种程序化地面材质；texuniform=true 使纹理按物理尺度重复，而不是把少数大格拉伸到 80 m 平面。取消反射，避免把轮子倒影误认成另一个轮子。测试对照了全部有接触 geom 的类型、尺寸、坐标、摩擦/碰撞标志，以及 body/joint/equality/驱动力范围，全部不变；10 s 站立 trace 逐值一致。

## 3. 键盘同时触发了原生显示热键

真实测试的 W/J/X 除进入 Teleop，也进入 MuJoCo 的默认显示逻辑，截图出现线框、关节轴/透明显示。这个问题不会让物理不积分，但会让机器人尤其轮子看起来“又变了”。当前驾驶模式同步时保持启动的 opt/user_scn flags，日常 UI 隐藏左右调试面板。最后的 flags 修正使用实际 API 对象做了复位单元检查；真实键盘全流程发生在这项最后修正之前，报告没有称已重新录制最终正常外观。

因此已有窗口必须重启才会加载最后显示修正；不会在用户操作时偷偷热替换或重启其窗口。

## 4. 跳跃不能靠把模型往上挪

J 的阶段为：下蹲目标 0.24 m、蹬地目标 0.30 m，并短时叠加每侧 140 N 支撑目标，随后恢复/落地。这些支撑力通过同一 VMC 变成腿电机力矩，仍受 ±30 N·m 限幅；轮 ±5 N·m 不变。没有写基座向上力、强写 qpos/qvel、去重力或打开闭链。

是否跳起看实际接触和运动，而非只看 target 变化：真实默认窗口的 J 动作从 z≈0.24923 m 到最高 ≈0.37668 m，双轮同时无接触约 0.24 s，随后落地；实际向上速度也记录。对应 motion.npz 存接触数/轮角/机身坐标，trace.npz 存六状态和实际腿长。

轮子在空中可以自由转，轮编码器积分不再等于机身位移。这次跳跃后里程计与真实 X 的差达到约 3.26 m，所以不能说已经实现飞行状态估计。驾驶层在跳跃期间不把自由轮速度拿去追绝对位置，当前只验了平地定时动作；地形、连续跳跃或实机仍未验。

## 5. 实测证据与操作

默认窗口用实际 XTest 按键启动/加速/停车/缩腿/复位/跳跃，模拟运行至 14.728 s，再由 Alt+F4 关闭：机身移动 1.324 m；行走区间左右轮分别转约 +17.13/-17.13 rad；Q 两次后实际左腿长约 .23818 m；跳起落地保持平衡。它与无头注入按键测试分别记录，不能互相冒充。

鼠标自动化在 X_SetInputFocus 报 BadMatch 后没有完成受控拖动；留下的交互窗口还在接收键盘，因此没有为了补证据抢占/强关它。日志明确该自动化未通过，不编造扰动力大小。最初沙箱无法连接 X11、测试脚本未判空退出139也保留，之后用桌面执行边界复验，未升级/重装环境。

运行已有解释器的 `python -B controller.py`，点击 3D 窗口取得焦点。W/S 加减速度、A/D 转向、Q/E 腿长、J 停稳后跳跃、X 停车、R 恢复目标。命令锁存，松开不自动停，须 X。输出始终在 E002/outputs 各新目录。

下一项最小任务是在不占用用户窗口时完成可重复鼠标扰动量测试；部署前仍需 IMU/编码器/接触与时序契约，当前不开始训练或实物操作。
