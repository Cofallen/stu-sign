# 叠加输入、旋转坐标与易读调参

现象是A/D转一段时间后停转或翻倒。最初只改角速度反馈/缓停仍失败；日志显示机器人在yaw≈±π/2附近卡住，腿长异常上升。这不只是松开制动问题，而是VMC摆腿Jacobian一直在世界X/Z平面投影，机身转90°后“前后”已不在世界X方向。

当前VMC用机身前向水平投影heading和世界竖直z构成随朝向旋转的摆腿平面。前向距离=heading·(轮心−髋轴)，求导包含heading自身变化；theta Jacobian由该平面角度导数得到。不能仅把控制器yaw符号改反或调大PID掩盖坐标退化。0/90/180/270°刚体旋转测试J最大差≈2e-15；左右共用闭链消元/朝向缓存，13个角度缓存前后差0，机构和惯量不变。

偏航改为角速度反馈，目标有.6rad/s²起停斜坡，差动轮力矩限幅留出平衡余量。实际偏航也停下后才恢复位置锁定，避免旋转中轮里程计轻微漂移引起纵向猛刹。公共roll/delta/yaw PID每步只更新一次，不能左右两次调用同一PID而重复更新D记忆。长度D允许以实测变化替代目标误差变化，避免跳变目标D冲击；原离散kd不是连续kd。原积分未加入输出，启用ki都为0，不宣称有PI。

parameters.py是统一调参入口：DRIVE驾驶、JUMP跳跃、PID所有初始化、CONTROL阻尼/限幅/周期、TARGET所有目标、REFERENCE覆盖规则、MONITOR倒地策略、LQR_FIT和LINEARIZATION离线标定参数。TARGET是初始目标，默认theta/phi/L0会被实测reset参考覆盖，要偏置请改REFERENCE。更改PID不是自动重标定K。用户已有强跳/PID参数先快照，不覆盖历史；失败后当前选已标定内环与200N/.34/.18m跳跃。

键位是正交输入：W/S控制平移，A/D或Shift控制偏航，Q/E腿长，J为独立请求，不再拒绝移动中起跳。Shift按住持续转，A/D更新记忆方向，松开缓停而不是锁存。真正同时按住Shift+W时键位查询要读取Shift_L/Shift_R，并处理Shift修饰下的抓键；只加一个GLFW按下回调不能得到真实释放。窗口/三维区约束仍保留，不读取其它程序文本。

jump.py按阶段直写，参数移出。实际离地才收腿，保持目标.24s，低空下降提前展腿，接触后恢复。加腿长目标限速，避免瞬间把支撑变成强负力。跳跃时保留W/S请求与惯性移动，但暂不使用轮里程计速度误差去追速度：空中轮子不能从地面获得推进力，收腿/空转轮速不等于机身速度。仍有姿态平衡输出，动作结束恢复正常速度反馈。当前移动J/静止J都实际保持收腿约.241s，上轮约.128s；提高的是收腿维持与轮底间隙，不保证COM峰值提高。

lqr.py用命名步骤分开linearize、solve_lqr、fit_ABK、get_K，矩阵每个元素显式行列polyfit，运行直接写Horner三次式。复杂闭链动力学放lqr_model.py供深入阅读；没有变成更简单的机器人或偷偷换K。现有系数文件、A/B/K和拟合审计差0；.33m处2.35%精度限制仍在。

跌倒不是退出条件：fall_events记录，默认倒地电机0减少地面猛打，扶正恢复，物理积分继续；不自动起身、不把失败改成功。NaN/Inf/数值警告仍停。第一次保持倒地力矩的主入口试验在4.585s数值异常，改输出策略后主入口完整10s无警告；真实交互约259N外力后倒地仍到24s。继续计时、继续站稳、自动起身是三件不同的事。

最终A/D两向20s，按11s再释放，转约±7.67rad，未倒；Shift两向20s转约±16.37rad，峰值±1.526rad/s，释放后<.0003rad/s。前进J/静止J各12s，最大倾角.023/.029rad并落地。真实W+J/Shift链路通过，首次窗口.879RTF失败保留；名称缓存后10s轨迹逐值相同，另一次含手动外力交互RTF.99899，但枚举脚本BadWindow失败，不能混成受控无扰动成功。独立复制到/tmp的10s检查通过。
