# 落地、制动、参数说明与独立地形

本轮不是单纯提高腿长P。现有P20000/D100000、速度3、跳跃附加300N高于之前验证值，电机仍30/5Nm，会更容易饱和。另一个更直接的问题是基座高度低于.12m就关闭平衡，落地压缩也会触发，因此P再大也可能坐地。当前只按倾角判倒地关电，低高度仍记录但不单独关支撑；NaN/数值警告仍保护，倒地不退出。

跳跃接触后轮速尖峰、腿还没伸回站立高度时，立刻恢复速度误差会错误驱动轮子。仅按接触计时恢复的试验失败保留。当前累计稳定接触（|基座vz|<.15），.1s后用.25s淡入，并乘腿长恢复权重；偏差超过.03m时不急于追轮速。最终静止J、W+J各12s未倒，末腿长.277923/.277924，证明指定平地案例已恢复站立，不代表任意地形落地已验收。

即走即停在物理上不是把qvel清零。当前采用1.2m/s响应优先默认、纵向制动斜坡4、偏航制动2，速度误差制动增益2、偏航P3。基础拟合K没改，但等效制动反馈改变，不能说它仍是同一个最优LQR；另做17长度线性检查和非线性试验。约1.17m/s前后释放后到.05以下.76/.75s，之前仅改目标斜坡约1.41s；Shift释放到.05rad/s约1s。减速明显改善但仍不是瞬停，也不是3m/s同样结果。

参数不能只给分类标题。PARAMETERS.md逐项列当前值/单位/作用，ARCHITECTURE.md给出真实数据流、时序、阅读顺序和边界，README恢复主图。目标初值会被实测reference覆盖，离线LINEARIZATION参数与运行PID不混成自动重标定。Ki原来未进入输出，当前启用Ki0，不伪称有积分。

terrain文件独立于原模型，用box组成10cm/级和20cm/级两组实心台阶，顶高.1/.2和.2/.4m；17°坡长2m、宽1.4m。原compiler为radian，角度17必须换.29670597rad；不能看名字叫ramp17就算验证角度。矩阵反算为17°，尺寸和原XML/网格hash检查通过。运行合并增量XML，默认flat不变，--terrain training --camera terrain打开自由总览。scene文件也进入新运行快照。程序接触统计要把新台阶视作地面，不能把台阶名称当机器人非轮碰撞。

几何是本项目原生编写，无外部下载/格式转换。地形加载/原点站立10s通过不等于上阶/上坡通过；轮半径.06m、步高.1/.2m不能默认靠滚动越过。下一项最小任务先验证10cm单级起跳/落点、阈值和接触，不一口气宣称所有台阶自动通过。

渲染960宽超过现有640离屏缓冲失败保留，改640×480后成功并目视核对，无需改原XML/环境。测试中间有未完整结束的目录，最终采用response_v3与final_code_v2，配置/版本/命令/原错误见[汇总](../../experiments/E002_original_controller/outputs/terrain_braking_20261110_131430/summary.json)与[报告](../../experiments/E002_original_controller/REPORT.md)。未验gas地形/3m/s急停/长期/跨机/实物/训练。
