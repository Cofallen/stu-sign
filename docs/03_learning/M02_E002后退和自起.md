# E002 后退制动与髋关节自起

基线的后退松键、换向和短腿后退均未复现偶发翻倒。降低后退参考速度及斜坡，减小换向期间的纵向参考变化。LQR 仍使用既有按腿长调度的 K，后退制动通过缩小速度误差倍数改变等效反馈。三项固定回归倾角峰值略降。要定位偶发翻倒，仍需包含真实操作前序、腿长和转向的轨迹。

VMC 里的腿长与摆角是闭链机构的任务空间量。自起时对四个主动髋轴使用关节位置 PD，左右轴方向相反，前后电机还叠加差动角度目标。轮电机提供短时辅助，所有力矩使用同一执行器限幅。40 N·m 在 E002 装载模型后设置给四个髋轴，同时更新 VMC 软件限幅。轮电机限幅仍为 5 N·m。

单个角度目标的探索只把机身推到另一个支撑姿态。分段髋关节目标能让指定正俯仰倒姿进入原 LQR 的小角度工作区。切回 LQR 时重新初始化轮编码器差分，避免把长时间摆腿和空转累计为回退位置目标。最后用地板双轮接触和速度确认稳定。复验命令、对照、失败和模型范围见 [E002 报告](../../experiments/E002_original_controller/REPORT.md)。

自起控制器现在在全部运行模式实例化，关卡模式和驾驶开关只决定输入来源。地形几何 ID 用于判断机器人是否接触地面和双轮是否重新支撑。无气弹簧模型在两种场景的平地区域通过，气弹簧模型虽然进入摆腿阶段，但未达到平衡接管条件。统一入口不能扩大同一条摆腿轨迹的动力学适用范围，复验命令和结果见 [E002 报告](../../experiments/E002_original_controller/REPORT.md#2026-11-12-场景自动上阶与默认自起)。

普通驾驶的输出归零来自自起失败。机器人倒地时，欧拉俯仰角不能单独区分侧卧和前后倒地，控制还检查机身坐标系中的世界竖直方向。新增规则避免只因中等倾角便在尚未触身时切断平衡。控制失败时保存完整 qpos、qvel 和电机指令，方便在仿真中复现。两个键位回放仍未恢复站立，见[排查和证据](../../experiments/E002_original_controller/REPORT.md#2026-11-12-普通驾驶倒地排查)。

此前 failed 状态只等待人工扶正，造成永久零力矩。现在失败后 0.5 s 自动回到 settle，再根据实际接触尝试摆腿或平衡。每次摆腿都有独立 attempt 编号，16 s 负向倒姿测试记录到三次非零髋力矩输出，最终仍未站稳。

当前只对双轮心均后摆的倒姿启动髋动作。把轮心相对机身原点的向量投影到机身 X 轴，正值为后摆。零轮力矩取消主动驱动，轮子可因接触被动转动。髋关节平滑摆腿能将测试倒姿带到小倾角，后续双轮支撑尚未稳定。[复验结果](../../experiments/E002_original_controller/REPORT.md#2026-11-12-仅后摆倒姿的髋关节自起)

## 2026-11-13 后摆长腿、收腿和 LQR

用户嵌入式状态机把倒地腿旋转、起身和正常平衡作为三个控制阶段。仿真里，沿用普通 LQR 的平均腿角会隐藏左右差异，而且欧拉 pitch 会在机身接近翻面时折叠。VMC 现在另给每条腿 `theta_body = atan2(-x, -z)`，其中 x、z 来自机身坐标下的髋轴到轮心向量。左右同位置角度同号，后摆为负。加上机身平面重力参考角再 wrap 得到 `theta_gravity`，用于 ±0.8π 判定。倒地还结合 IMU 和碰撞，后摆准备则看机身参考角、趴姿、双侧实测腿长和角速度。

`leg_rotate.py` 的 `LegRotate` 把长度和摆角误差变成虚拟轴向力与摆腿力矩，通过 `vmc.py` 的机身角 Jacobian 转为髋轴力矩。两类 PD 使用同一闭链机构。默认只有后摆长腿趴姿可以收腿。其他倒姿保持零输出，可显式开启伸腿和转腿准备。正向测试中只靠静态腿长 PD 缩短了腿，但机身仍趴在接触面，加入限幅且平滑的髋轴目标后，才进入 LQR 接管姿态。早期 LQR 每轮限 1 N·m 时未站稳，采用阶段渐入和每轮 3 N·m 上限。收腿和摆髋期间轮力矩仍为 0，轮子可被地面带动。

复跑 `python -B controller.py --headless --recovery-trial=1.45`，由 0.283/0.274 m 收至 0.222/0.223 m，5.026 s 回到正常控制。加 `--recovery-prepare` 时在这一例先伸腿再后摆，6.381 s 站稳。负向倒姿转到身后后机身仍未趴下，气弹簧版收腿也未通过。调参、限幅和录像见 [E002 报告](../../experiments/E002_original_controller/REPORT.md#2026-11-13-后摆长腿收腿与-lqr-接管)。

+2.0 rad 初始倾倒最后可落成贴地且俯仰接近零的姿态，因此仅用 IMU 大角度会漏判。新的状态机利用低机身和机身碰撞接触确认趴地，再用左右腿机身角和实际腿长确认状态 2。这里用的是仿真接触真值。复测用 `python -B controller.py --headless --recovery-trial=2.0`，也可加 `--recovery-roll` 检查侧向倒姿。[结果和阶段](../../experiments/E002_original_controller/REPORT.md#2026-11-13-多角度倒姿与状态-2)

2026-11-13，E002 状态 2 直入 LQR 的九点短测中，5 点进入 LQR，0 点通过完整自起。2.0 rad 进入后未在接管窗口内脱离机身触地。下一最小任务是在真实状态 2 回放中先建立双轮承重，再测 LQR。 [直入 LQR 对照](../../experiments/E002_original_controller/REPORT.md#状态-2-直入-lqr-对照)
