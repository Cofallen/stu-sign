# 腿长增益拟合、质量分配与腾空收腿

本轮问题是固定K只对应一个工作点，旧lqr.py还保留chuan的符号参数且没有被控制器导入；因此仅在旧函数里改质量并不会改变实际运行。当前实现改lqr.py做完整模型离线采样/拟合，lqr_controller.py实际使用K(L)，jump.py独立处理跳跃。

质量不随腿长变化。机身16.877574kg，单侧8.438787kg；左腿六连杆1.597924kg、右腿1.598327kg，轮各.4904kg，整机21.054625kg。左右各使用一半机身，不把机身算两次；腿包含完整闭链后支路，轮子单独分类。旧轮径.05、旧轮质量.572、旧等效杆惯量不能混进当前.06m轮径模型。旧符号公式中用几何长度代替平行轴项质量的写法也不能当正式惯量。当前动力学直接读取XML的完整质量、惯性主轴和姿态，构型变化改变COM/有效惯量而非凭空改质量。

K的单位和输入也要对应：完整双侧模型施加对称虚拟输入Tw/Tp，解出的是每轮/每侧摆腿反馈，不是把全机力矩随便一分为二。支撑基项按机身一半+该侧腿质量，再加reset静态力矩解出的trim；因trim=标定力−新基项，初始总支撑没有被重复加重。分配质量的账与物理XML质量不是两套互相替代的模型。

采样：对.18:.02:.34m各长度在完整模型上用least_squares求闭链/腿长/近零qacc静态点，保留全部关节/约束/接触。gas用自己的静态点，不混用无弹簧力矩。局部平面切空间冻结腿长、滚转、偏航，保留theta/s/phi三个坐标；对位置、速度和虚拟输入做中心差分得到六状态A/B，再以原Q/R解CARE。求导临时去除不可微的关节干摩擦并恢复，实际仿真摩擦不改。该投影是近似，最大切空间残差约.0022645；不是把完整机构改成六个关节，也不代表全非线性全局稳定。

拟合：x=(clip(L,.18,.34)−.26)/.08；K=C3*x³+C2*x²+C1*x+C0，系数shape=(4,2,6)，每一元素独立三次拟合。A/B也保存，运行只有K需要求值，系数数组缓存，Horner计算不做CARE。lqr_controller左右各有100Hz时钟/输出缓存，按各腿实测L得到K_left/K_right；原六状态平均估计不变，大幅不对称腿长控制未验收。可选MPC仍用nominal A/B，不能称为时变MPC。

证据：训练矩阵相对误差约.136%；8个中点最大2.35%（.33m），初设2%精度检查失败保留，闭环特征值全部稳定。提高拟合阶数/改差分epsilon的诊断未消除此局部差异，当前未为了报成功修改精度阈值。非线性8个长度各8s、Q/E扫腿10s、前后10s、跳跃10s通过；默认站立/前倾/gas默认/MPC默认各10s也通过。下一项最小工作是.32–.34m密集采样+新的留出点，必要时再选分段拟合，不把已看过的中点当新留出。

跳跃拆分：JumpControl.request/observe/update输出目标，不写qpos/qvel/基座外力。下蹲.20m/.40s、蹬地.34m/200N，连续无接触6ms且向上速度>.05后才收腿；目标.18m，最短.10s/最长.22s，COM向上速度降至.45m/s开始展回站立长，接触后恢复。腾空额外支撑置零。实际空中最短约.224m，并非写目标就能瞬间达到.18m。J仍需停稳，极短点按限制由X11后端决定。

公平对照同K、同蹬地，只切换tuck_enabled：轮底间隙.162626→.242151m（+7.95cm），COM最高点.536600→.536689m几乎不变，基座最高点.469331→.466384m。收腿改变身体与腿之间的相对位置，能提高轮底过障间隙；没有外部额外冲量时，整机质心主要遵循弹道，不能保证更高。机身参考点、整机COM和轮底间隙必须分别记录。图和原始trace在报告对应目录。

失败边界：固定K直接阶跃和部分高腿长缓变会倒，不用这些失败轨迹标定。首次拆分漏key_events初始化已修复并完整重测。第一次HUD窗口RTF.873失败；缓存增益/只算K后的默认真实窗口14/14.00084s，RTF.99994，含额外按键，非独占时序实验。没有硬实时、跨机、gas混合驾驶/跳跃或长期验收；未训练、改驱动或装依赖。

复验：E002目录用既有mjlab解释器运行python -B controller.py，三维区Q/E、W/S、停稳J；--headless --duration 10 --case pitch-plus作回归。lqr.py --variant no-gas --points 已保存工作点 --output 新JSON可重算，旧输出拒绝覆盖；工作点生成脚本是运行证据，重采样先另建目录。新的运行依赖本地gain_schedule.json，实际离线复制验证另有copy_check.json，不读父工程。
