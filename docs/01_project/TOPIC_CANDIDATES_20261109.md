## 3. 候选 A：自适应世界模型与预测控制（首推）

**研究问题**：固定模型在负载或摩擦变化后容易预测失准。能否利用近期“动作—响应”历史，让模型更快恢复准确预测，并让控制受益？

**最小演示**：同一实物、同一低速命令，在几种预先定义的负载/地面条件下，显示实际响应、固定模型预测、自适应模型预测。随后比较现有 LQR 与世界模型辅助控制的跟踪误差和恢复过程。负载可以在每次试验开始前安装，不要求运动中人为加砝码。

**模型具体干什么**：根据可测/可估计状态、实际下发的控制命令和历史上下文，预测未来一小段机身姿态、角速度、轮速等。训练需要动作条件预测和多步验证；只有“看历史后直接输出动作”属于历史策略，不自动成为世界模型。

**最值得研究的一处改进**：噪声和物理变化都会产生预测误差。研究时间窗口、更新速度或可靠性判断，能否减少“把测量噪声当作环境变化”的错误适应，同时保留对真实变化的反应。只选其中一个明确问题，先测量缺陷再设计方法。不能声称一定能仅凭误差唯一识别故障原因。

**适合你的实现边界（定题后才实现）**：

- 利用现有 LQR 获取首批有时间戳的数据；世界模型可以先于轮腿 PPO 开始，不被多地形训练阻塞。
- 从低维状态预测器开始，比较固定模型、历史条件模型与带误差反馈的上下文更新。在线第一版只更新隐状态/小型上下文，保持大网络权重固定；不把它称为在线重训全部网络。
- 模型验收后，在仿真中研究短视界预测控制或有界残差修正，保留现有低层控制作为基线。优先单一低速任务；具体残差通道、扭矩/电流/参考值单位必须依据现有控制接口确定。
- 若模型只用于改善估计，而没有参与规划或想象策略优化，应将交付写成“世界模型辅助感知/控制”，不要冒称完成完整模型式 RL。

**最小比较**：现有 LQR；固定模型预测控制；同结构/同数据的历史模型；同结构加在线上下文更新；理想真实参数仅作为仿真上界。若引入额外安全回退或状态估计器，各组也要公平对齐。

**何时算有价值**：留出负载、摩擦组合或变化过程下，多步预测更准确；误更新更少；闭环恢复/跟踪受益，且推理开销可接受。单纯降低训练集 loss 不足以支持结论。

**已有工作与新颖性边界**：PETS、RMA、TD-MPC2，以及近期 Online Adaptation to Latent Physical Properties 都覆盖其中一部分。“历史编码 + 模型 + 在线隐变量更新”的拼接不能自动算创新。需要针对轮地接触、测量噪声与动力学变化，提出一个可对照检验的具体改进；没有验证前称为研究假设。

**面试可展示**：数据契约、动作条件模型、长短期误差、在线适应机制、模型偏差如何影响控制、机载时延与失败分析。与你现有控制和硬件经验衔接最直接。

## 4. 候选 B：可微世界模型与高效策略学习

建议题目：**《面向轮腿机器人控制的可微世界模型误差抑制与策略学习研究》**。

**研究问题**：世界模型能预测，并不保证在里面优化出来的策略到了仿真/实物上仍有效。模型的多步误差、动作梯度误差或分布偏移，可能让策略利用模型漏洞。

**最小演示**：同一平地命令任务、相同数据与计算预算，比较普通模型训练、你改进的模型训练，以及 PPO 基线；记录样本数、总墙钟时间和控制表现。

**可选改进点，只选一个**：多步训练目标怎样兼顾近端精度和远端误差；或局部动作敏感度约束能否改善短视界策略梯度。有限差分在接触切换处可能不稳定，需要独立分析。自适应展开已有 MBPO/MACURA 等前作，不能把它本身写成首次提出。

**与你目标的关系**：最接近 SuperMimic 那类“通过世界模型训练策略”的算法研发。它要求同时理解数据回放、模型训练、自动微分、价值估计和策略更新，调试面比 A 更宽。

**主要风险**：PPO 仍未在当前轮腿跑通；完整闭链训练后端待验证；模型预测改善未必带来策略改善。本机 8 GB 需要先验证小配置，不能套用 H100 的训练时长。SuperMimic 的训练模型使用仿真上下文，不意味着部署时能直接获得真实摩擦/质心参数。当前归档代码为第三方，不等同作者官方复现。

**合理收口**：平衡与低速命令任务即可，不把人形动作库、跳跃、楼梯、跨本体同时放进毕设。若选 B，A 的在线实机模型适应降为后续工作。

**面试可展示**：解释 BPTT 与 PPO 梯度差异；证明你改的是模型学习/优化方法；讲清预测质量与策略收益不一致的失败案例。

## 5. 候选 C：预测世界模型辅助地形感知

建议题目：**《融合本体与深度感知的预测世界模型及轮腿机器人地形适应控制研究》**。

**研究问题**：机器人如何结合相机看到的地形与自身运动历史，形成对未来可通行性/身体响应有用的表征？

**最小演示**：平地到缓坡或低矮障碍前，模型预测短期观测/状态变化，策略根据预测表征调整速度或姿态。先选一种地形变化，不把“全地形”列成默认验收。

**可研究的具体改进**：感知延迟或短时图像缺失时，预测记忆能否维持有用表征；比较无记忆视觉策略、普通循环策略与预测监督的世界模型。必须进行动作条件未来预测，单独预测当前地形类别不足以构成世界模型贡献。

**前置与风险**：相机、同步标定、机载算力均未确认；需要额外视觉数据。WMP 原仓库 README 标注约 23 GB 显存，不能直接复制其训练配置到当前 8 GB 笔记本。纯本体感知通常只能在接触或运动响应出现后推断变化，不能宣称看见尚未接触的前方坑洞。

**面试可展示**：动作条件序列建模、多模态融合、表征与控制、感知延迟分析。与视觉世界模型岗位更接近，但比 A 多了数据与传感器工程门槛。

**推荐条件**：明确有可用深度相机、同步链路和额外训练资源，并且愿意把视觉表征学习作为主线时再选。否则放在毕业后扩展。

## 8. 实验设计比增加奖励项更重要

下面是定题后的预注册原则，当前没有任何训练/实机新结果：

- 数据划分按完整试验、日期和物理配置，不能将同一轨迹相邻帧随机分到训练与测试。归一化只用训练集。各方法使用相同数据、状态估计器、任务指标和可部署信息。
- 固定目标/代价/奖励后比较模型方法；若中途修改，所有基线一起重评。不靠不断变奖励掩盖方法无收益。研究模型和规划也仍需明确任务目标。
- 第一层比较预测：持续值/线性模型、普通 MLP、同容量历史模型、所提方法；报告 1/5/10/20 控制步的误差及对应秒数，单位归一化方法写清。
- 第二层比较变化：静态训练范围内、留出参数组合、缓变/突变、纯噪声扰动分别测试。上下文表征有效不等于能唯一辨识真实摩擦或质量；缺乏激励时要承认不可辨识。
- 第三层比较控制：跟踪 RMSE、恢复时间、跌倒/终止次数、控制输入与限幅比例、实测推理 p50/p95 和失约周期。在线多步预测要记录候选动作假设，不能拿真实未来传感器偷喂模型。
- 三个独立训练种子是正式算法比较的起点，评测试验数与时长在基线小试后锁定；不把相邻窗口当独立重复试验。实物独立重复、异常停止和人工接管都要计入。
- 在正式对照前定义成功阈值、评测时长和留出条件。此时尚无当前实物的误差/噪声分布，因此不伪造“提升 30%”“两秒适应”的指标承诺；阈值必须在看最终测试集之前固定。

实物链路建议：现有 STM32H723/MC02 保留低层控制与超时回退；上位机先只记录与预测，随后在仿真和影子运行通过后才接入有界修正。实际频率、单位、限幅来自当前硬件和控制代码，不预设 1 kHz 或把电流直接当力矩。此处是实施前设计条件，本轮没有向机器人发送任何指令。

## 9. 面试定位与成果形态

适合首先证明的能力是“小型动作条件世界模型 + 动力学适应/预测控制 + 实物评测”。它能覆盖模型研发的重要环节，但不等价于已经掌握大规模视频基础模型训练。

检索到的[智元世界模型校招条目](https://agirobot.jobs.feishu.cn/campusrecruitment/position/7670760310362671411/detail)在官方域名搜索摘要中列出：硕士及以上、生成模型/序列建模、PyTorch、世界模型与规划/策略及评测。直接页面在读取工具中无正文，因此仅作为岗位要求样例，不保证该条目始终开放，也不能推广成所有企业的学历要求。你的本科背景需要把岗位筛选与项目能力建设同时考虑。

推荐投递叙事为：机器人学习/模型式控制/世界模型算法相关研发或实习，逐步扩展到视觉序列世界模型。避免仅写“调 PPO 让机器人走路”，也避免把一个低维预测器包装成通用基础模型。

面试材料应包括：

1. 一张数据与模型闭环图，能讲清每个张量来自哪里。
2. 一份公平比较表，说明何时有效、何时不如简单基线。
3. 一段可对应日志的实物演示；预测曲线与控制改善能对应上。
4. 一份方法推导和关键模块解释；能够独立修改和复验。
5. 一页成本与局限：数据量、训练总耗时、机载时延、不可观测因素和失败案例。

项目内容以实测为准，简历数字待实验后填写。无需承诺顶会或大厂录用，也不要求为了简历主动换机器人。
