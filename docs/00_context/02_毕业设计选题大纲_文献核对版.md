## 1. 今天推荐提交的题目

**《面向机器人动作跟踪的可微世界模型持续学习方法研究》**

英文参考：Continual Learning of Differentiable World Models for Robot Motion Tracking

一句话解释：机器人依次学习走路、跑步和其他动作时，研究如何用有限的历史经验更新世界模型和控制策略，使其学习新动作时尽量保留旧技能。

推荐把研究边界定为：**同一机器人、固定动力学、动作任务顺序到达、固定记忆预算、仿真验证。** 第一阶段选择少量动作完成对照，G1 作为主验证目标；Isaac Lab 跨仿真器测试作为可选扩展。

“持续学习”比“可持续学习”更准确：这里讨论的是 continual learning，即不断吸收新任务时的保留与迁移；“可持续”容易被理解为能耗或环境可持续性。

## 2. 可直接用于选题表的内容

### 研究背景与意义

机器人动作控制需要在多种任务之间复用动力学知识。SuperMimic 通过学习可微世界模型，并在模型的短时想象轨迹中反向传播来优化动作跟踪策略，为降低训练成本提供了方法基础。[SuperMimic 原论文](https://arxiv.org/abs/2610.28480)

当动作数据按阶段到达时，新增训练可能影响旧任务表现。已有持续强化学习研究说明，历史保留、正向迁移和资源限制需要共同评估。因此，本课题关注有限记忆约束下的机器人技能增量学习。[Continual World](https://arxiv.org/abs/2105.10919)

### 研究目标

基于现有机器人仿真项目，构建动作任务的顺序学习流程，分析世界模型与策略的遗忘表现，研究结合有限经验回放和稳定更新约束的改进方法，并评估其在旧技能保留、新技能学习效率及资源开销方面的表现。

### 主要研究内容

1. 分析可微世界模型与动作跟踪策略的训练机制，建立可运行、可评测的基线。
2. 构建顺序动作任务及统一评测流程，区分模型预测退化与策略行为退化。
3. 研究固定容量下的经验保留方法，以及模型、策略的稳定更新约束。
4. 通过对照和消融实验评价方法，分析适用条件、代价与失败情况。

### 预期成果

形成一套可复查的实验流程、一种持续学习改进方案、对照与消融结果，以及毕业论文和演示材料。具体性能提升幅度由实验确定。

## 6. 要回答的三个研究问题

**RQ1：顺序训练究竟会出现什么退化？** 每学完一组新动作，就在仿真器中重测所有旧动作，同时在固定留出转移上检查世界模型的单步与多步误差。允许出现“模型预测仍好，但策略变差”或“基本没有遗忘”的结果。

**RQ2：有限记忆应该保留哪些经验？** 在相同总容量下，对比均匀保留与按任务、接触状态或运动特征覆盖的保留方式。检验结构化选择是否比强随机基线更有效。

**RQ3：怎样稳定更新，又不妨碍学习新动作？** 对比模型一致性、策略行为保持及两者结合，观察旧技能保留与新技能适应速度的权衡。

世界模型通常用于训练期间提供预测与梯度；如果部署时只执行策略，模型变化不会直接改变冻结策略的动作。它可能通过后续训练中的梯度间接影响策略。归一化器等共享状态也可能改变行为，必须纳入检查。

## 7. 拟研究的方法：先做两个模块

### 模块一：固定容量的经验回放

保留能支持模型拟合和旧任务更新的短轨迹窗口，包括状态、动作、下一状态、目标信息、终止标记及必要的参考动作片段。

先建立均匀或 reservoir 保留基线，再比较按动作组与接触状态分层的选择。高预测误差样本可作为候选扩展，需防止缓存被异常样本占满。

记忆预算按固定字节数或固定窗口数定义，所有旧任务共用，不能随技能数量无限增长。“占历史数据 5%”只能作为附加描述，因为历史数据增长时它并非固定容量。模型快照、统计量、适配器和任务元数据也要单独报告开销。

### 模块二：模型与策略的稳定更新

在新数据和回放数据上继续训练，同时研究两类约束：

- 模型侧：在保留窗口上限制新旧模型预测差异，并以实际下一状态监督保持预测正确。
- 策略侧：在旧任务回放状态和目标上，限制新旧策略输出偏离，结合必要的旧任务想象更新。

教师模型/策略可在阶段边界生成快照。蒸馏旧输出不能保证旧输出正确，也不能替代闭环控制评测；相应内存和计算必须计入。

归一化统计先作为独立诊断变量：比较继续更新与冻结等简单方案。每任务一套统计量或适配器需要额外任务身份和存储，若采用，应明确假设。

概念流程：新动作到达 → 仿真采集 → 与固定容量旧经验混合 → 更新世界模型 → 在想象轨迹中更新策略并保持旧行为 → 在仿真器中评测全部已见动作 → 更新缓存。

暂不把 LoRA、自动任务发现、生成回放、跨机器人或真机在线学习列为必做内容。基础方法确有瓶颈后，再选一个扩展。

## 8. 最小可行实验

### 平台与任务

先在倒立摆或其他低维任务上验证训练和评测流程；这是控制实验成本的手段，不能代替人形动作结论。随后选择 G1 的三组动作，如走路、跑步和舞蹈；具体片目与数量以可用数据清单为准。先固定身体参数，暂不混入负载、摩擦和机器人形态变化。

参考动作库与环境转移缓存需要分别定义权限：本方案暂允许在阶段结束后使用缓存内的旧参考窗口进行回放，但不允许重新遍历完整旧动作库来生成无限旧训练数据。离线评测集可以保留用于测试，不参与训练。若允许全量旧目标继续用于想象更新，应单列为另一种实验设置。

### 对照组

| 组别 | 作用 |
|---|---|
| 顺序微调 | 检查是否存在遗忘，不预设它必然最差 |
| 固定容量均匀/reservoir 回放 | 核心强基线 |
| 回放＋稳定更新约束 | 检验约束是否有增益 |
| 结构化回放＋稳定更新约束 | 完整候选方法 |
| 全数据联合训练 | 使用额外数据访问权限的参考结果，不能视为数学上界或完全公平的竞争组 |

先完成前三组判断问题是否值得继续；正式阶段补完整方法、联合训练参考和必要消融。若资源允许，再加入 EWC 等经典对照。

### 评测指标

设 `R[k,i]` 为学完阶段 k 后，在动作组 i 上的固定协议平均回报，各组等权：

- 最终平均性能：`A = (1/K) Σ_i R[K,i]`。
- 后向迁移：`BWT = (1/(K−1)) Σ_(i=1..K−1) (R[K,i] − R[i,i])`，K > 1。
- 遗忘：`F = (1/(K−1)) Σ_(i=1..K−1) (max_(k=i..K) R[k,i] − R[K,i])`。
- 新任务学习效率：达到预先规定回报阈值的交互步数、运行时间，或固定预算内的学习曲线面积；未达阈值如实标注。
- 如报告零样本前向迁移：`FWT = (1/(K−1)) Σ_(i=2..K) (R[i−1,i] − b[i])`，其中 b[i] 为匹配初始化及评测协议的未训练参考性能。它与“新任务学得更快”不是同一指标。
- 控制质量：成功率、跌倒率、位置/姿态跟踪误差；定义统一终止条件和评测时长。
- 模型质量：固定留出轨迹上的单步、多步预测误差，说明状态分量与归一化方法。
- 成本：环境交互、梯度更新次数、墙钟时间、GPU 型号与用时、峰值显存、缓存与模型存储。

提前终止的失败片段必须计入，不能只对存活步骤平均而隐藏失败。各方法使用相同评测条件。

### 消融与公平性

优先做四项：去掉模型约束、去掉策略约束、替换为均匀回放、改变缓存容量。核心配置争取至少三个训练种子，汇报均值与波动；单次探索结果明确标注。初期固定一个任务顺序，正式结论增加反向或随机顺序。

主比较固定总环境交互预算，记录不同方法的更新次数和实际耗时；另按固定运行时间比较效率。不要只固定迭代数，就声称算力相同。超参数在验证设置选择，最终测试不用于反复调参。

## 9. 预期贡献如何写

目前可以写成三项研究目标：

1. 建立可微世界模型动作跟踪的顺序学习评测流程，量化模型与策略的不同退化表现。
2. 研究有限记忆选择与协同稳定更新，比较其相对强回放基线的收益和代价。
3. 分析何种任务差异、记忆容量和训练设置下，该方法有效或无效。

本科层次可优先完成清晰对照和一个有依据的改进；硕士层次通常还需要更充分的邻近方法比较、泛化验证或机制分析，最终以导师要求为准。

不预先承诺“零遗忘”“正迁移必然发生”“三倍加速”。暂不命名新算法；等实际改进明确后再决定名称。
