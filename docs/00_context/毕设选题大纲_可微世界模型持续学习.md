## 0. 一页纸版（先看这个）

**一句话问题**：SuperMimic 证明"一具身体的动力学只需要学一次，就能摊销整个动作库"；但它的动作库是**封闭**的——数据一次性给齐、训练一次做完。如果动作是**一条一条陆续到来**的（新舞种、新受试者、新负载），这个"只学一次"的模型还能不能**增量地学下去而不忘掉旧的**？

**一句话方法**：把"一次性拟合"改造成"流式吸收"——技能适配器（结构隔离）+ 动力学核心集（有界回放）+ 模型-策略一致性约束（稳定化），在固定显存与固定数据预算下更新世界模型与策略。

**一句话证据**：在 LAFAN1 的 40 条动作上构造 5~6 个技能 shard 的顺序任务流，报告 ACC / BWT / FWT / 遗忘率 / 单技能吸收成本，并给出"视界放大遗忘"这一可证伪的机理解释。

**一句话意义**：让"世界模型 + 动作跟踪"从**离线训练一次**走向**部署后持续生长**——这是人形机器人真正落地时必须具备的能力，也是当前可微世界模型文献里几乎空白的一格。

**为什么这个题适合你**：你不是从零开始。基线代码、数据、仿真器、评测桥、失败分析你都跑通过（`supermimic-mjlab` + `mjlab_ws` + `isaaclab/eval_g1.py`），方法只需要动 4 个文件（`trainer.py` / `networks.py` / `sampler.py` / `config.py`）。这决定了你 6 个月里能把力气花在**算法**上，而不是环境上。

## 3. 问题从哪来（三个观察，逐层收紧）

### 3.1 论文自己给出的、反直觉的观察
数据集从 1 h 增长到 264 h，世界模型的 8 步预测误差始终在 0.007–0.011。作者的解释是：**所有动作由同一具身体执行，新增 clip 提供的是"关于共享动力学的更多证据"，而不是要求更大容量**。

这句话有两个含义，第二个没人接着做：
- 已经做了的：容量不用涨 → 所以一个模型能摊销整个库。
- **没做的**：证据是"可累加"的 → 那么**按顺序累加**（一次只给一小块）理应也行。

**这正是持续学习的定义。** 论文用"一次性看到全部证据"验证了前半句，但没有验证后半句。你的毕设就是去验证它，并在它不成立时补上补丁。

### 3.2 论文承认的局限
- "并发训练其实等价于串行"——作者知道这是串行，但没测串行会不会忘。
- 世界模型学不到"事件"：去掉了 root 速度扰动以保证确定性，所以对"被推""踩到异物"这类状态跳变没有概念。
- 单 seed、主实验只在训练动作上评测。

### 3.3 部署现实
真实的人形动作系统不会"数据到齐再训一次"：
- 新动作由动捕/视频重定向**陆续**产生，每条都可能带新的风格与接触模式；
- 旧动作数据可能**不能长期保留**（LAFAN1、BONES-SEED 都是有许可的第三方数据；自采数据有隐私与存储成本）；
- 重训一次要小时级 GPU 时间，而"明天要演示一个新舞蹈"是常态；
- 负载、地面、电机老化会让**同一具身体的动力学本身漂移**。

> **研究问题（一句话）**：在"技能分片顺序到达、旧数据不能全留、显存与算力固定"的约束下，如何让一个可微世界模型与其策略**持续吸收新技能**，做到旧技能不退化（BWT ≈ 0）、新技能学得更快（FWT > 0），并且单技能吸收成本显著低于从头训练？

## 4. 研究现状与定位

四条线，各一句话说清"他们做到哪、留了什么口子"：

| 线 | 代表工作 | 做到哪 | 留的口子 |
|---|---|---|---|
| **物理动作模仿** | DeepMimic (2018)、AMP、PHC、BeyondMimic (2025)、SONIC (2025) | 单条/多条动作的高质量跟踪；SONIC 用 128 卡 PPO 堆规模 | 每个技能都要重训；规模化靠算力不靠算法 |
| **可微仿真 + 解析梯度** | DiffTaichi、Brax、SHAC (2022)、SuperTrack/SuperDyno、RWM (2025)、**SuperMimic (2026)** | 短视界 BPTT 穿过学到的动力学，样本效率高 1~2 个量级 | **全部是离线、一次性、封闭数据集** |
| **通用基于模型的 RL** | Dyna、World Models (2018)、Dreamer v1–v3、TD-MPC2 | latent 空间想象、长视界、鲁棒 | 面向"一个任务/一个环境"，不是"技能库"；且多为像素/低维状态 |
| **持续学习 / 持续 RL** | EWC (2017)、PNN (2016)、LwF、GEM/A-GEM、CLEAR (2019)、PackNet、Adapters (2019)、LoRA (2021)、Continual World (2021)、Loss of Plasticity (Nature 2024) | 分类与游戏基准上方法成熟；持续 RL 有 benchmark | **几乎没有人把它接到"可微世界模型 + 全身动作跟踪"上**；控制里的"遗忘"该用什么度量也没共识 |

**定位（一句话）**：现有工作要么"可微世界模型但离线"，要么"持续学习但不在可微世界模型里、也不在全身控制里"。**这个交叉格是空的**，而且空得有道理——因为一旦模型会漂移，策略就是在"移动的地基"上做 BPTT，耦合效应比分类任务复杂得多。这正是可以做出东西的地方。

> 注意表述纪律：不要说"首次提出持续学习"，那是 1990s 就有的领域。要说"**首次在可微世界模型驱动的全身动作跟踪中系统刻画并解决遗忘**"。范围限定越清楚，越站得住。

## 5. 科学问题与可证伪假设

### 5.0 先把因果链说清楚（否则整个题会被一句话问倒）

**最容易挨的一刀**：部署时只用策略 π，根本不用世界模型，那世界模型漂移凭什么让旧技能变差？

必须回答清楚。遗忘有三条路径，轻重不同：

| 路径 | 机制 | 是否直接伤害旧技能 | 怎么测 |
|---|---|---|---|
| **P1 参数覆盖** | 新技能的梯度直接改写共享的 π 参数 θ | 直接 | 冻结 WM、只训 π 的对照实验 |
| **P2 共享模块漂移** | goal 编码器 / 解码器 / `RunningNorm` 把旧目标映射到错误的特征或尺度 | **直接且致命** | per-skill 隔离归一化器与编码器，看恢复多少 |
| **P3 梯度偏置** | WM 漂移 → 新技能的想象梯度有偏且幅度偏大 → 对 θ 的覆盖更"暴力"、credit assignment 错位 | 间接，但被 H 放大 | `δ_grad`：同一批新技能状态上，旧/新 WM 反传得到的策略梯度夹角与模长比 |

于是"视界放大遗忘"（H1）说的不是"WM 误差直接扣旧技能的分"，而是：**H 越长，P3 这条间接路径越强，θ 被推得越偏，旧技能被覆盖得越狠。** 这句话在论文里必须写明白，否则 H1 会被当成因果错置。

对应地，`δ` 要拆成四项：`δ_pred`（模型）、`δ_ret`（策略）、`δ_norm`（归一化器）、`δ_grad`（梯度方向）。**这四项的分解图，就是第 4 章的核心图。**

### RQ1（现象）：顺序学习会遗忘吗？忘在哪？
- 把 40 条动作切成 K 个技能 shard，顺序训练，测每个 shard 训完后**所有**旧技能的归一化回报与成功率。
- 模块级归因：把遗忘拆到 **世界模型 / 目标编码器 / 共享解码器 / critic / 归一化器（`RunningNorm`）** 五个部件上，逐个冻结或单独回放，看谁贡献最大。

### RQ2（机理）：三条路径各占多少？

定义四个可测的漂移量（前三个用旧 shard 的留出窗口算，最后一个用新技能状态算）：

- `δ_pred`：旧 shard 上 8 步预测误差的增量（模型漂移，对应 P3 的"燃料"）；
- `δ_ret`：把**新策略直接放进仿真器**跑旧技能，归一化回报的下降（纯策略漂移，对应 P1；部署时不用 WM，所以这一项干净）；
- `δ_norm`：`RunningNorm` 的均值/方差偏移量（P2 的隐性杀手）；
- `δ_grad`：新旧 WM 在同一批新技能状态上反传得到的策略梯度之间的**夹角余弦与模长比**（P3 的直接度量）。

**三条可检验的子假设**：
- H2a：**P2 主导** → 只做 per-skill 归一化器隔离，就能恢复大部分旧技能性能；
- H2b：**P1 主导** → 只要回放旧技能的状态分布，即可恢复，与 WM 是否漂移无关；
- H2c：**P3 主导** → 遗忘随 ‖δ_grad‖ 增大而增大，且 H 越长越敏感（与 H1 耦合）。

三个子假设互斥且都能被一次实验分开，这是第 4 章能写成"分析"而不是"调参记录"的原因。附带一个便宜的实用发现：如果 H2a 成立（我预期它至少贡献 20–40%），那"per-skill 归一化器"就是一篇小论文都值得写的东西，而它的实现只有十几行。

### RQ3（方法）：固定预算下能否做到"不忘 + 学得快"？
- 预算固定：回放缓存 ≤ 全量的 5%、每技能新增参数 ≤ 全模型 3%、单技能 GPU·h 有上限。
- 目标：BWT ≥ −0.02（相对 oracle 的归一化回报），FWT > 0，单技能吸收成本 ≤ 从头训练的 1/3。

### H1（可证伪假设，本毕设的"骨头"）：视界放大遗忘

设世界模型单步状态误差 ≤ ε，转移关于状态 Lipschitz 常数 L，则 H 步想象的累积误差满足

```
‖ŝ_H − s_H‖ ≤ ε · (L^H − 1) / (L − 1)          (L ≠ 1)
```

若新技能训练使 ε 增大 δ（漂移），则旧技能回报下降的量级约为

```
ΔJ ≈ C · δ · (L^H − 1) / (L − 1)                (C: 奖励 Lipschitz × 视界)
```

**预测**：固定 δ，遗忘随 BPTT 视界 H **单调增大**；固定 H，遗忘随 δ 线性增大。
**检验**：H ∈ {8, 16, 32, 64} × 三档漂移强度（用回放比例 0% / 5% / 50% 控制 δ），在旧技能上测回报下降，拟合斜率。

这个假设的价值在于：它把"遗忘"从"玄学现象"变成一个**有方向、有斜率、能被证伪的量**；而且如果成立，它直接给出方法设计原则——**抗遗忘要优先稳模型，而不是稳策略**（因为误差被 H 指数放大）。如果证伪（比如遗忘与 H 无关），那说明主导因素是策略侧的，也是有价值的结论，方法章节跟着改。

> 理论纪律：这个界在接触丰富处 L 很大、会松到无意义。**要在论文里明说**：本文不把它当保证，只当作"标度假设"用来设计实验。评审最反感的是把松界吹成定理。

## 6. 方法：WEAVE（World-model Elastic Adaptation with Verified Experience）

> 名字可换。核心是三件事：**结构隔离**、**有界记忆**、**稳定更新**。

### 6.0 总体框架

```
            ┌──────────────── 第 k 个技能 shard 到来 ────────────────┐
            │                                                        │
   新数据 ──► 采集（π_k 在仿真器里跑新动作）──► 写入有界缓存 B_k       │
            │                                        │               │
            │                    ┌───────────────────┴──────┐        │
            │                    ▼                          ▼        │
            │         M2 动力学核心集选择           旧核心集 C_{k-1}   │
            │         （分层 + 最大最小多样性）        （≤5% 预算）    │
            │                    └───────────┬──────────────┘        │
            │                                ▼                       │
            │                    M1 世界模型更新：                   │
            │                    冻结主干 + 新增技能适配器 φ_k        │
            │                    （共享主干只用 C_k ∪ C_{k-1} 微调）  │
            │                                │                       │
            │                                ▼                       │
            │                    M3 一致性约束：                     │
            │                    · WM 信赖域（新旧模型在 C 上预测一致）│
            │                    · 策略锚定（旧技能成功率不低于阈值）  │
            │                    · 归一化器冻结 / 慢更新              │
            │                                │                       │
            │                                ▼                       │
            └──────────────► 想象 + BPTT 更新 π_k，写入技能码 z_k ────┘
```

### 6.1 M1：技能适配器（结构隔离，抗遗忘的第一道闸）

现状：`WorldModel` 是一个 3×2048 的 MLP 主干，所有技能共用；`RunningNorm` 全局共享。
改造：
- 主干**冻结**（或极低学习率），每个技能 shard 注入一个低秩适配器（LoRA 式，rank r = 8/16）到主干的前两层 + 一个 FiLM 调制（scale/shift）；
- 增加一个**技能码** z_k（one-hot 或学习到的 embedding，dim = 8），与世界模型已有的 goal g 和 sim context ξ 拼接进入条件输入；
- 目标编码器/解码器共享，但加 per-skill FiLM；critic 共享（critic 漂移对旧技能影响较小，可后验验证）。

**参数量**：3×2048 主干约 1.26×10^7 参数；rank-16 LoRA 在两层上约 2×16×(2048+2048) ≈ 1.3×10^5，约 **1%**。符合 §5 的 3% 预算。

**为什么这样能抗遗忘**：旧技能的适配器参数**从未被新数据碰过**，遗忘只能通过共享主干发生，而主干被冻结 + 只用核心集微调。这把"灾难性遗忘"从"全网参数漂移"压缩成"主干的小幅漂移"，量级可控。

### 6.2 M2：动力学核心集（有界记忆，抗遗忘的第二道闸）

现状：`buffer_steps=1000` × 4096 envs 的环形缓存，且 `sampler.py` 的 `ReturnBasedSampler` 按回报分箱采样——**它是为"单次训练"设计的，没有"技能"概念**。
改造：
1. **分层**：用现成的可微正运动学（`algo/kinematics.py`）算足端高度/速度，把每条转移标上"接触相位"（腾空/触地/蹬伸/摆动）× 关节组；在每层内做配额。
2. **多样性**：在手工特征空间（接触相位 + 关节角速度 + 基座角速度）上做 greedy k-center，保证覆盖而不是随机抽样。
3. **两种加权策略对比**（这是个小而实的贡献点）：
   - 误差加权：用当前 WM 的预测残差给样本加权（"模型不会的地方多留"）；
   - 优势加权：用 critic 的 advantage 幅度加权（"决定成败的地方多留"）。
4. **预算**：|C| ≤ 5% 全量（约 5×10^4 条转移，~20 MB），可离线导出成 npz，**旧动作原始数据可以删**——这一点直接回应 §3.3 的存储/许可约束。

**要测的**：同等预算下，uniform / 多样性 / 误差加权 / 优势加权 四种核心集的"每 MB 抗遗忘收益"。这张表很可能是论文里最实用的一张。

### 6.3 M3：模型-策略一致性约束（稳定更新的关键）

这是最有"算法味"的一块，因为 BPTT 的策略梯度对模型版本极度敏感：**模型一漂，旧策略的想象回报就是假的**。

三个约束，按成本从低到高：
- **M3-a 归一化器冻结**：per-skill 保存 `RunningNorm` 的 (mean, var)，推理时按技能码切换。成本几乎为零，但可能吃掉一大块隐性遗忘（见 RQ2 的 `δ_norm`）。
- **M3-b 世界模型信赖域**：在核心集 C 的状态上，约束新旧模型单步/多步预测的差异
  `‖f_{ω_k}(s,a) − f_{ω_{k+1}}(s,a)‖ ≤ τ`，用 KL 或直接 MSE 惩罚实现。本质是"函数空间 EWC"，比参数空间 EWC 更适合 MLP（参数空间 EWC 在 1.26×10^7 维上 Fisher 估计噪声很大——**这一点可以作为"为什么 EWC 在这里不 work"的实验结论**）。
- **M3-c 策略锚定（约束优化）**：把"旧技能成功率 ≥ 1−η"写成约束，用拉格朗日乘子自适应调节回放/正则权重。实现上就是一个对偶变量，几行代码；好处是不用调 λ。

### 6.4 训练算法（伪代码）

```
输入：技能流 S_1..S_K，核心集预算 B，适配器秩 r
初始化：主干 ω、技能码表 Z、核心集 C ← ∅
for k = 1..K:
    1. 采样 z_k ~ Z（新技能新建码）；挂载适配器 φ_k
    2. 采集：π_{k-1} + 适配器在 S_k 上跑 N 步，写入 B_k
    3. 更新核心集：C ← Select(C ∪ B_k, budget=B)        # M2
    4. 拟合世界模型（冻结主干，只训 φ_k；主干每 m 轮用 C 微调一步）：
         L_WM = Σ_{j<k_w} ‖f_ω(s_j, a_j, ξ, z_k) − s_{j+1}‖²  (在 C 上)
                + λ_term · BCE(终止头)
                + λ_tr · ‖f_{ω_k} − f_{ω_{k-1}}‖²          # M3-b
    5. 想象 + BPTT 更新 π_k（旧技能成功率为约束）：
         θ ← θ + α ∇_θ Ĵ_imag(θ)，  s.t.  success_old ≥ 1−η   # M3-c
    6. 记录：所有旧技能的 R_i^(k)，以及 δ_pred / δ_ret / δ_norm / δ_grad
```

### 6.5 与基线的本质差异（答辩必问）

| | 从头训练 | 顺序微调 | EWC | 回放 | **WEAVE** |
|---|---|---|---|---|---|
| 旧数据 | 全留 | 不留 | 不留 | 留 5% | 留 5% |
| 旧技能会退化 | 否 | **是** | 部分 | 部分 | 目标：否 |

## 7. 实验设计

### 7.1 两级实验台（这是让 8 GB 笔记本也能做研究的关键）

| 级别 | 平台 | 单次实验 | 用途 |
|---|---|---|---|
| **L0 代理台** | `mjlab_ws/slide_test`（1 自由度滑块）、`cart_test`（小车倒立摆） | **秒~分钟级** | 调通 CL 回路、扫超参、验证指标代码。这里跑 50 组，比 G1 上跑 1 组还快 |
| **L1 主台** | `supermimic-mjlab` + G1 + LAFAN1 | 小时级 | 主结果、消融、机理实验 |
| **L2 泛化** | Isaac Lab（`isaaclab/eval_g1.py`） | 分钟级 | sim2sim：把策略搬到另一套物理引擎，检验不是"过拟合 MuJoCo Warp" |

**方法论价值**：先在 L0 上把"遗忘曲线"跑出来，再去 G1。这一步能省掉你 70% 的调试时间，而且写进论文的"实验方法"一节会显得很专业。

### 7.2 数据与任务序列

40 条动作按**动作族**切成 6 个 shard（已按你本机 `g1_lafan1_40/` 的实际片目盘过，数目对得上）：

| Shard | 内容 | 实际条数 | 难度 | 想考察什么 |
|---|---|---|---|---|
| S1 | walk1 / walk2（走） | 6 | 低 | 基础步态，作为"旧技能"的锚 |
| S2 | walk3 / walk4（走，换受试者） | 6 | 低 | **同族对照**：几乎没有分布偏移，专门测"纯参数覆盖"（P1） |
| S3 | run + sprint（跑/冲刺） | 6 | 中 | 与走共享动力学，测**正迁移**（FWT > 0？） |
| S4 | dance1 / dance2（舞） | 8 | 中高 | 上肢/躯干协调，与步态差异大，测**干扰** |
| S5 | fallAndGetUp1-3（摔与起） | 6 | 高 | 接触模式剧变（躺地/撑地），测**接触相位遗忘** |
| S6 | jumps + fight + fightAndSports | 8 | 高 | 极限动态与快速变向 |

**S1→S2 这一对是整个实验设计的支点**：两段都是"走"，只是受试者不同。如果连这里都掉点，说明遗忘主要来自参数覆盖（P1），与分布偏移关系不大；如果这里不掉、而 S4/S5 之后掉，说明是分布偏移在驱动。**一个几乎零成本的对照，能直接把 §5 的三条路径分开。** 这一步在开题时讲出来，会显得实验设计是想过的。

两种顺序都跑：**易→难**（S1→S6）与**难→易**（S6→S1）。顺序敏感性是 CL 的标准关注点，成本只多一倍，结论更硬。

> 若算力吃紧：退化为 **4 shard**（walk 6 + run/sprint 6 + dance 8 + fallAndGetUp 6 = 26 条，约 1.6 h 动作），保留"同族对照"与"接触剧变"两个关键条件。**降级方案要在开题时就写清**，别到 3 月才发现跑不完。

### 7.3 基线与对照（8 组）

| # | 名称 | 说明 | 回答什么 |
|---|---|---|---|
| 1 | **Oracle-Joint** | 全数据一次性训练 | 上界；也是"遗忘"的参照系 |
| 2 | **Seq-FT** | 顺序微调，无任何保护 | 下界；遗忘有多严重 |
| 3 | **Seq-EWC** | 参数空间 Fisher 正则 | 经典 CL 在 1.26e7 维 MLP 上灵不灵 |
| 4 | **Seq-LwF** | 在核心集状态上蒸馏旧 WM 输出 | 函数空间正则 vs 参数空间 |
| 5 | **Seq-Replay** | 同预算均匀回放 | 回放本身贡献多少 |
| 6 | **Seq-Adapter** | 只加适配器、不回放 | 结构隔离本身贡献多少 |
| 7 | **WEAVE-full** | M1+M2+M3 | 完整方法 |
| 8 | **WEAVE w/o M3** | 去一致性约束 | M3 的边际贡献 |

**公平性纪律（评审一定会问）**：
- 同 **GPU·h** 比较，不只是同数据量；
- 同 **峰值显存**比较（否则"多留数据"就成了不公平优势）；
- 每格 **≥ 2 seed**，报均值 ± 极差；主表建议 3 seed；
- Oracle-Joint 也要限在同一显存预算下（降级配置），否则上界不可比。

### 7.4 指标（定义要写死，别到写论文时再吵）

设 `R_i^(k)` = 第 k 个 shard 训完后，在技能 i 上的**确定性**归一化回报（每条 clip 一次 60 s rollout，取均值）：

```
ACC  = (1/K) Σ_i R_i^(K)                        # 最终平均性能
BWT  = (1/K) Σ_i ( R_i^(K) − R_i^(i) )          # 后向迁移，负数=遗忘
FWT  = (1/(K−1)) Σ_{i≥2} ( R_i^(i−1) − b_i )    # 前向迁移，b_i=随机策略
F    = (1/K) Σ_i ( max_k R_i^(k) − R_i^(K) )    # 遗忘率
T_i  = 达到 0.85·R_i^oracle 所需 GPU·h           # 吸收成本
S_i  = 成功率（无 fall / anchor 终止）           # 控制里更直观的指标
```

外加四个诊断量：`δ_pred`、`δ_ret`、`δ_norm`、`δ_grad`（§5 RQ2），以及**单技能新增参数占比**、**核心集 MB**、**峰值显存**。

### 7.5 消融矩阵

| 维度 | 取值 | 想说明 |
|---|---|---|
| 适配器秩 r | 0（=无适配器）/ 4 / 8 / 16 / 32 | 隔离强度 vs 容量 |
| 核心集比例 | 0% / 1% / 5% / 20% / 100% | 记忆的边际收益曲线 |
| 核心集策略 | 均匀 / 多样性 / 误差加权 / 优势加权 | M2 的选型依据 |
| 一致性权重 λ_tr | 0 / 0.1 / 1 / 10 | M3-b 的敏感度 |
| 视界 H | 8 / 16 / 32 / 64 | **H1 假设主实验** |
| 归一化器 | 全局 / per-skill / 冻结 | `δ_norm` 的独立贡献 |
| 顺序 | 易→难 / 难→易 / 随机×3 | 顺序敏感性 |

### 7.6 算力预算（必须先实测标定）

**硬约束**：RTX 4060 Laptop **8 GB**、14 GB RAM、16 核。你现有 config 的默认值（2048³、`wm_batch=2048`、4096 envs）在这台机器上**跑不动**，必须降级。

| 配置 | 环境数 | WM 宽度 | wm_batch | H | policy_batch | 估算单轮 | 单次实验（6 shard×1200 iter） |
|---|---|---|---|---|---|---|---|
| **P0 笔记本** | 512 | 1024×2 | 256 | 16 | 256 | 1.5–3 s | **4–6 h** |
| **P1 租用 4090** | 2048 | 2048×3 | 1024 | 32 | 1024 | 0.8–1.5 s | **3–4 h** |

按 P0 估：8 组 × 2 seed = 16 次 × 5 h ≈ **80 GPU·h ≈ 3.5 天连续跑**（分三周夜跑，完全可行）。
按 P1 估：16 次 × 3.5 h ≈ 56 h ≈ **¥250–450**（4090 按需 ¥3–8/h）。

**建议策略**：
- **P0 做开发与消融**（便宜、迭代快、不排队）；
- **P1 只跑主表 + H1 主实验**（要"好看且可信"的那几张图），预算 ¥500 以内；
- 第 1 周必须做一次**实测标定**：跑 100 iter 记时，把上表的估算换成实测值写进开题报告。**开题报告里写"估算"比写"拍脑袋"安全。**

### 7.7 评测协议（照抄上游，别自创）

- 确定性策略，每条 clip 一次 60 s rollout，不做域随机化、不加观测噪声；
- 报归一化回报（未折扣和 / 最大可达和）+ 成功率 + anchor 位置/旋转误差；
- 与上游 README 的口径对齐（40/40、0.895、8.1 cm、0.053 rad），这样你的 Oracle-Joint 才有外部参照；
- **所有实验固定 seed 列表并公开**（`[0,1,2]`），checkpoint 与 config 一起存档。

## 14. 附：选题答辩 3 分钟口径

**（30 秒）问题**
> SuperMimic 证明一具身体的动力学只需学一次就能覆盖整个动作库，但它的动作库是封闭的、一次给齐的。真实系统里动作是一条条来的，旧数据还不一定能留。我想问：这个"只学一次"的模型，能不能持续地学下去而不忘掉旧的？

**（30 秒）现状**
> 动作跟踪这边都在比"一次训得多好"，规模靠堆卡；持续学习这边方法很成熟，但都在分类和游戏基准上。两边中间这一格——可微世界模型驱动的全身控制里的持续学习——基本是空的。

**（60 秒）方法**
> 三件事：一是给每个新技能挂低秩适配器、冻结主干，从结构上把旧技能隔离；二是维护一个 5% 预算的"动力学核心集"，按接触相位分层、按多样性选，旧数据可以删；三是加一致性约束——新旧世界模型在核心集状态上的预测要接近，同时把归一化器按技能隔离，因为 BPTT 的策略梯度对模型版本特别敏感。

**（30 秒）证据**
> 在 LAFAN1 四十条动作上切六段，按受试者和动作族分，顺序喂。报 ACC、后向/前向迁移、遗忘率、单技能吸收成本。还提出一个可证伪的假设：遗忘会被 BPTT 视界指数放大，所以稳模型比稳策略更重要——用 H 从 8 到 64 的网格去验证。

**（30 秒）意义**
> 让世界模型从"离线训一次"变成"部署后还能长"。这是人形机器人真正进场景的前提。

### 老师可能追问的 8 个问题（提前准备答案）

1. **这和一次性多任务训练有什么区别？**
   → 约束不同：数据只来一次、旧数据要删、算力固定。多任务训练假设三者都无限。
2. **为什么不直接 LoRA 微调策略就行？**
   → 策略的梯度来自世界模型；模型漂了，策略的"想象回报"就是假的。所以模型侧必须一起管。
3. **控制里的"遗忘"怎么度量？分类是准确率，你是什么？**
   → 归一化回报下降 + 成功率下降 + anchor 误差上升；再分解成模型漂移、策略漂移、归一化器漂移三项。
4. **为什么不干脆把世界模型做大？**
   → 论文自己测了：数据 1 h→264 h，8 步误差不涨。瓶颈不是容量，是稳定性。
5. **你的成本怎么可能比从头训练低？**
   → 只训 1% 的适配器 + 5% 的核心集，主干复用；给出 GPU·h 与峰值显存两条曲线。
6. **新技能和旧技能动力学解释冲突怎么办？**
   → 适配器提供隔离，冲突极端时退化为"路由"；容量上限是本文局限，写进展望。
7. **创新点有多大？**
   → 不吹首创：一是首个系统实证与基准，二是一个可证伪的机理假设，三是一个可复用的配方。三条都能指到表。
8. **万一根本不遗忘呢？**
   → 那就是"可微世界模型天然抗遗忘"的结论，且能把遗忘源精确定位到归一化器与目标编码器；论文照样成立，方法章节改为"何时需要保护"。
