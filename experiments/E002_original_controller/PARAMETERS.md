# 参数逐项说明

唯一修改入口：`LQR_six/parameters.py`。修改后重启。下表由当前参数实际值生成；运行PID与离线标定内环分开，不应假定更改PID后K已自动重算。

## 怎样调，先看什么

1. 先把速度/跳跃参数保持在已验证值。先记录实际速度、倾角、腿长和力矩是否饱和，再动增益。
2. 坐地不一定是P不足：原先高度低就断电、轮速误差在落地时误触发、力矩饱和都能导致坐地。当前只按倾角关闭平衡，落地反馈按稳定接触/腿长渐入。
3. 腿长P从2000提到20000并不能令实际支撑力增加10倍，因为六电机仍限30/5Nm；反而可能持续饱和。D沿用离散变化形式，不是连续微分增益。所有启用ki=0，原PID未将积分加入返回值。
4. “松开即发制动命令”与“刚体速度瞬时归零”不同。机器人质量约21kg，需要先改变倾角再减速；不能用清qvel或冻结画面伪造停止。
5. 超过拟合域.18–.34m的普通腿长输入只是保留的试验接口，不代表极限腿长已稳定验收。台阶/坡面也不是平地K的自动通过保证。


## RECOVERY

`RECOVERY` 定义倒地去抖、趴姿、双腿后摆和最小腿长、准备动作及力矩限制。角度用 rad，长度用 m，时间用 s，力矩用 N·m。髋关节伸缩与旋转 PD 在 `leg_rotate.py`，收腿、摆髋和交接状态在 `recovery.py`。`RECOVERY_DIRECT` 和 `RECOVERY_PREPARED` 分别保存自然后摆和主动准备后使用的髋轴参考轨迹与 LQR 渐入时间。两种轨迹的调参和仿真证据见 [REPORT](REPORT.md#2026-11-13-后摆长腿收腿与-lqr-接管)。
