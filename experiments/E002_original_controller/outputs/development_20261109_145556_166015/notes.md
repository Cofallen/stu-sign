# 开发记录（非正式通过案例）

- 原型 v1 在含干摩擦的静止点直接差分 qacc，得到不适用的高阻尼模型；10 s 结果机身已接地，不通过。
- v2 仅在离线矩阵计算时去掉干摩擦，随后恢复正式模型；未闭合左右腿差动与正确 yaw 符号时，约 1 s 后支撑高度失效，不通过。
- v3 恢复作者的左右腿同步修正并核对 yaw 方向，从 +0.03 rad 俯仰恢复，原型积分 10 s；其控制矩阵用于新六状态模块。临时计算中的摩擦设置不写入 XML，正式仿真使用原摩擦。
- controller.py 首次启动曾因函数内 import mujoco.viewer 使 mujoco 被识别为局部变量而出现 UnboundLocalError，未开始仿真；改为 from mujoco import viewer as mjviewer。
- 真实首次传感器对接把 XML framequat/body 的惯性主轴当机身，导致 t=0 判摔倒；原始退出 1 结果保留。传感器改读机身 xquat，IMU 速度仍用原 site gyro。
- 以上初期原型主要输出到控制台，此处保留源码/观察摘要而非冒充完整原始日志；之后每次入口执行均在独立 outputs 留存代码、配置、日志、结果与退出状态。
