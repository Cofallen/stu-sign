# 用 mjlab 实现 SuperMimic 式轮腿训练

## 1 原理与传统 PPO 的区别

原论文在 Unitree G1 上做参考动作跟踪。算法用刚体仿真转移拟合共享可微世界模型，在模型里短时展开，把回报对动作的梯度沿轨迹反传到策略。作者方法还使用可微奖励与终止建模以及价值估计。 [论文](https://arxiv.org/abs/2610.28480v1) · [作者代码](https://github.com/HybridRobotics/supermimic)

| 环节 | E003 PPO | E004 轮腿适配 |
|---|---|---|
| 数据 | mjlab 积分生成训练轨迹 | mjlab 负责采样，再拟合一步观测模型 |
| 更新信号 | 真实回报与 GAE，优化裁剪后的概率比 | 模型内展开的奖励对动作求导 |
| 任务 | 纵向速度和偏航 | 沿用同一命令、物理模型和控制接口 |
| 部署 | actor 输出六路力矩 | 更新后的 actor 输出同样六路力矩 |

E004 是独立的简化适配。使用 E003 PPO 权重热启动，保留观测归一化统计。此次省略人形动作库、终止预测头、价值 bootstrap 和论文的大规模评测。

## 2 在 mjlab 写任务并采样

先看 E003 教程第 1–4 节，了解完整 XML、动作顺序、28 维观测和 reward。E004 的 task.py 将相同模型装配成 ManagerBasedRlEnv，选 velocity 预设。动作每 10 ms 更新一次，仿真内部以 1 ms 积分。train.py 每轮用 actor 输出加 0.025 标准差探索噪声，采样 48 个控制步。已终止和超时的转移剔除，因为自动 reset 返回的新状态可能是下一回合初值。最近 12 轮放入 replay，约 1/8 环境只作当轮验证。

## 3 写可微动力学模型

输入为 28 维归一化观测和 6 维动作。MLP 用 ELU，宽度 34→256→256→19。预测观测索引 3 到 21 的 19 个变化量，命令和上一动作有确定的更新方式。将差量除以观测尺度，尺度至少为 0.05。训练每轮做 120 个 512 样本的 AdamW 更新。

```python
delta_target = (next_obs[:, 3:22] - obs[:, 3:22]) / scale
delta_pred = world(torch.cat((normalize(obs), action), dim=1))
loss = (delta_pred - delta_target).square().mean()
```

验证环境的平均单步误差用于检查拟合趋势。该 MAE 混合姿态、速度和关节角等单位。多步误差需要固定留出轨迹和输入序列单独评测。

## 4 写模型内策略梯度

冻结 world 的参数，保留输出对输入和动作的导数。从真实观测中采样起点，在世界模型中走 5 步约 50 ms。每步输入新动作，预测新状态，把预测状态送回 actor。按 0.97 折扣求和，对负回报调用 backward。再解冻世界模型并用更新后的 actor 回到 mjlab 采样。

想象奖励重用站立姿态、前进速度、偏航速度、侧滑、水平角速度和动作代价。省略腿长和跌倒项，所以这一版限于固定腿长平地。额外以系数 10 惩罚偏离初始 PPO 的动作，降低策略利用预测误差的程度。日志检查留出单步误差、想象回报与非零梯度。训练真实环境的奖励只用于任务本身，此策略优化使用的是 imagined_reward。

## 5 部署并复验

按 README 训练并保存 actor.pt 和 world_model.pt。部署读取 actor.pt，重建 28 维观测和归一化，取确定性均值动作，写回原生 MuJoCo 的六个 motor。在有桌面的终端运行 python -B deploy.py。窗口默认用键盘控制：W/S 前后、A/D 左右转、X 停车、R 重置。加 `--scenario demo` 才会每五秒切换预设命令。无桌面加 --headless 并查看 trace.csv。世界模型只在训练中使用。要比较两种方法，请在同一留出种子和命令上分别测试 E003 初始权重和 E004 更新权重。
