# 任务总览与当前进度

更新：2026-11-09。当前主线为指定复旦轮腿模型上的控制与可微世界模型实验。旧稿中的 G1、算力估计与预计创新保留为历史资料，不作为当前结果。

## 已完成和当前边界

- M00：取得候选仓库，现有 MuJoCo 3.11.0、mjlab 1.6.0、Isaac Sim 4.5.0.0 导入通过；未实例化 SimulationApp。
- M01 当前正式模型：[完整并联闭链两版本](../02_milestones/M01_parallel_linkage.md)。14 个显式铰链、4 个闭合销接全部保留，14 个关节和四处销接相对转动均经实际动态检查；8 个被动轴不直接施加驱动力矩。
- M01 历史：标准 V4 六关节简化模型虽通过其自身 CPU 冒烟，但遗漏完整连杆运动，不满足用户要求，撤回正式模型地位，保留实验记录。
- M01 外观纠正：旧录像错误地把碰撞凸包当作机身外观并统一涂蓝；现已恢复全部源视觉三角面，按用户选择使用上游 MJCF 的白色机身、深灰轮胎。视觉和碰撞分组，250 步对照确认外观不改变动力学。
- M01 历史气弹簧串联两版本的运动结果只对简化机构有效，不能用于完整闭链验收。当前两版本已改为原生并联结构，安装点使用上游明确命名的气弹簧 sites，刚度/阻尼/预载仍未做真机标定。
- 原生并联的 10 mm 残差已通过同一销轴上连接标记点的轴向对齐修正，未移动连杆/转轴。默认闭环误差约 1e-15 m，动态最大约 4.42e-7 m；原始源文件未改动。increase URDF 的惯量问题仍单列历史，不用于当前模型。
- 原始仓库保持干净；现有环境没有依赖安装、升级或卸载。
- 未完成：自由直立控制、mjlab GPU 任务、Isaac Lab 物理验证、PPO、actor 导出、世界模型训练。没有训练成绩。

## 下一项最小任务

2026-11-09 最新选题讨论：用户目标为世界模型研发与企业面试，明确要求本轮以多个候选为主、不编写算法代码。结合用户报告的 LQR 实物、2027 年 5 月与每周 20–30 h 条件，优先建议 A“自适应世界模型与预测控制”，备选 B“可微世界模型与策略学习”、C“多模态预测感知”；[三个候选与条件路线](TOPIC_CANDIDATES_20261109.md)。尚未确定最终选题，现有里程碑未据此宣称通过或自动启动。

已归档 [12 篇论文、8 份代码](../../references/READING_GUIDE.md)，静态下载检查见[阶段记录](../02_milestones/M00_research_selection.md)。实物 LQR 是用户自述进度，本轮没有上机复验。此前[闭链约束建议](../03_learning/M05_00_算法选题检索.md)降为备选专题，不再作为首选。定题后的模型任务仍需以下 M02；LQR 日志与离线预测研究可在接口明确后开展，不必等待多地形技能。

以 `assets/robots/infantry_parallel/` 完整闭链模型开始 M02，先选定无弹簧或阻尼版并固定配置。重新定义真实驱动顺序、8 个被动轴的状态、SI/坐标/四元数、限幅、physics_dt/control_dt/decimation、actor/critic/世界模型状态、轮角处理、历史缓存与 terminated/timeout，再做 mjlab 最小 reset/step 验证。不得沿用旧串联版的 6 关节状态映射。

命令只从前向速度和偏航角速度开始；高度有几何调节能力，但闭环可控范围尚未验证，不能直接加入“已支持”列表。不假定横向速度独立可控。

GPU 设备不可见时准确记录执行边界，不修驱动或换环境。世界模型工作随后在同一简单任务开展；论文动作跟踪复现与命令任务方法迁移分开报告。暂不为复杂技能预建大量未运行代码。
