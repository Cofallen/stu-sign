# runs：项目级运行证据

例如模型检查命令会创建一个新目录，里面记录当时配置、日志、结果和录像。[独立小项目](../experiments/README.md)的输出在各自的 `outputs/`，从小项目 README 找入口与结果。

**找结果先看 [INDEX.md](INDEX.md)**，其中区分正式闭链验收、历史简化模型和资料获取记录；解释结论看对应阶段报告。

- `m00_environment/`：环境、资料获取、工作区静态检查。
- `m01_model/`：机构、几何、外观与物理诊断，含失败和历史版本。
- `m02_standing/`：项目级 LQR/MPC 站立基线及汇总。

每次运行新目录，名称含用途和 Asia/Shanghai 时间。至少保存命令、解释器、版本/源码、配置、退出状态、日志与验收。训练再保存种子、交互数、全部训练成本、checkpoint 和独立评测。

历史目录及 metadata 不覆盖；不把“最后一个目录”默认当成最佳结果。正式采用记录由阶段报告和总览指向。同一阶段多窗口也各建自己的 run，避免输出冲突。

后续共享数据集放实际创建的 `data/` 并建立来源清单；交付冻结包放实际创建的 `deliverables/`，两者都应回溯到具体 run。
